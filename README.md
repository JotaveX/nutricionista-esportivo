# 🥗 Nutricionista Esportivo — Landing Page

> Landing page profissional para nutricionista esportivo, com frontend em HTML/CSS e backend para formulário de contato.

### 🌐 [Ver online → nutricionista-esportivo.vercel.app](https://nutricionista-esportivo.vercel.app/frontend/index.html)

## 🚀 Stack

| Tecnologia | Uso |
|---|---|
| **HTML5** | Estrutura da página |
| **CSS3** | Estilização e responsividade |
| **TypeScript** | Lógica do frontend e backend |
| **JavaScript** | Scripts auxiliares |
| **Vercel** | Deploy e hosting |

## 📦 Estrutura do projeto

```
nutricionista-esportivo/
├── frontend/            # Landing page (HTML, CSS, TS)
├── backend/             # Servidor para formulário de contato
├── .gitignore
└── LICENSE              # MIT
```

## ⚡ Como rodar localmente

### Pré-requisitos

- Node.js >= 18
- npm ou yarn

### Frontend

```bash
# Clone o repositório
git clone https://github.com/jotaveX/nutricionista-esportivo.git
cd nutricionista-esportivo/frontend

# Instale as dependências (se houver)
npm install

# Abra o index.html no navegador ou use um live server
npx serve .
```

### Backend

```bash
cd nutricionista-esportivo/backend

# Instale as dependências
npm install

# Inicie o servidor
npm start
```

## 🖥️ Funcionalidades

- Design responsivo (mobile-first)
- Seções: hero, serviços, sobre, depoimentos, contato
- Formulário de contato funcional com backend
- Deploy automatizado na Vercel
